# TV dashboard demo - Přehled staveb

Statické demo (HTML/CSS/JS, bez buildu) inspirované designem dashboardu z reelu. Všechna data jsou smyšlená (odznak „Vzorová data“).
Plátno 1920x1080 se škáluje na libovolnou obrazovku. Obrazovky: Přehled, Obchod, Harmonogram, Sklad, Vozidla, Finance (klávesy 1-6, Esc zavře detail).

Lokálně: `python3 -m http.server` a otevřít http://localhost:8000
